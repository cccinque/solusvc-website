# Solus Ventures

Official website for [Solus Ventures](https://solusvc.com/), a venture capital firm investing in one-of-none private technology companies.

Solus Ventures focuses on category-defining companies across frontier technology, artificial intelligence, aerospace, defense, proprietary data, hard technical execution, and compounding networks.
